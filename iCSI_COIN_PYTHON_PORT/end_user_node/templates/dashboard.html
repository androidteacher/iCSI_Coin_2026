Download Standalone Miner

1. Download the miner package (includes Python script & library):

📥 Download ZIP

2. Prepare Python Environment:

# Unzip the file
unzip icsi_miner.zip
cd icsi_miner

# Create Virtual Environment
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install Dependencies
pip install -r requirements.txt

3. Start Mining:

python3 miner.py --url http://127.0.0.1:9342 --user user --pass pass

💡 Tip: Add --address <YOUR_WALLET> to mine rewards directly to your wallet!

iCSI_Coin GPU Miner (Proxy Edition)

High-performance mining using ccminer with a Python proxy for accurate reward tracking.

📥 Download GPU Miner Package

Prerequisites

  • WINDOWS OS ONLY (The miner executable is for Windows).
  • Python 3.x Installed (Required for the proxy script).
  • NVIDIA GPU with up-to-date drivers.
  • iCSI_Coin Node running locally on port 9342 (RPC).

Setup Instructions

1. Edit `run_miner.bat`:

  • Right-click run_miner.bat and select Edit.
  • Find the line: set ADDRESS=<YOUR_WALLET_ADDRESS>
  • Replace <YOUR_WALLET_ADDRESS> with your actual wallet address.
  • Save the file.

Usage

Double-click run_miner.bat to start.

What happens?

  1. Launches Mining Proxy (Port 9340 -> Node 9342). Injects your wallet address.
  2. Launches ccminer to connect to the proxy and start hashing.

Troubleshooting

  • "python is not recognized": Install Python and check "Add to PATH" during installation.
  • "Connection refused": Ensure your Node is running and fully synced.
  • "Hashrate shows 0": Wait 10-20 seconds for the first job to be processed.
