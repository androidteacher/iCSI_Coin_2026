API Documentation

Complete reference for interacting with the iCSI Coin node programmatically. Base URL: http://localhost:<PORT>

🔐 Authentication

Login (Cookie Method)

POST
/api/auth/login

Authenticates a session and returns a cookie (Optional alternative to explicit body auth).

# Login and save cookie
curl -c cookies.txt -X POST http://localhost:8080/api/auth/login \
     -H "Content-Type: application/json" \
     -d '{"username": "admin", "password": "securepassword"}'

💰 Wallet

📍 iCSI Address Format

An iCSI Coin address is the RIPEMD-160 hash of your public key, written as raw hexadecimal — exactly 40 hex characters (20 bytes). Unlike Bitcoin, it is not Base58Check-encoded and has no fixed prefix, so it can start with any character and looks like a random hex string (it will not begin with a 1).

Example:

9c1185a5c5e9fc54612808977ee8f548b2258d31

List Wallets

AUTH POST
/api/wallet/list

Returns all wallets and balances.

curl -X POST http://localhost:8080/api/wallet/list \
     -H "Content-Type: application/json" \
     -d '{"username": "admin", "password": "securepassword"}'

Create Wallet

AUTH POST
/api/wallet/create 
curl -X POST http://localhost:8080/api/wallet/create \
     -H "Content-Type: application/json" \
     -d '{
           "username": "admin", "password": "securepassword",
           "name": "Savings"
         }'

Send Coins

AUTH POST
/api/wallet/send

Sends amount coins to the to address. There is no from field — the node automatically gathers the funds from across your wallet's own addresses and returns any change to you.

curl -X POST http://localhost:8080/api/wallet/send \
     -H "Content-Type: application/json" \
     -d '{
           "username": "admin", "password": "securepassword",
           "to": "9c1185a5c5e9fc54612808977ee8f548b2258d31",
           "amount": 50
         }'

Network Stats

AUTH POST
/api/stats

Returns current block height, difficulty, and mining info — including the estimated network hashrate (based on the last 10 blocks).

     -H "Content-Type: application/json" \
     -d '{"username": "admin", "password": "..."}'
